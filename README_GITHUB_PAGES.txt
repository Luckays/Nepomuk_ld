GitHub Pages export for project Nepomuk

How to publish
1. Create a new GitHub repository
2. Upload the contents of this folder to the repository root
3. Push to branch main
4. In GitHub repository settings enable Pages with GitHub Actions
5. The included workflow will deploy the site automatically

Entry point
- index.html

Included
- 2D viewer
- 3D Potree viewer
- panoramas
- cloud.ply
- Potree octree data

Important
- This is a public static site
- Anyone who can open the site can also fetch the point cloud files in the browser network layer
